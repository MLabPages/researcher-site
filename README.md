# M-Lab クラフト広場 (researcher-site)

授業や研究から生まれたアプリを、実際の画面を見ながら探して試せる広場です。用途・キーワード検索、画面の拡大、感想や質問の共有に対応しています。ビルド不要の静的サイト(HTML/CSS/JS)。

- 公開URL: https://mlabpages.github.io/researcher-site/
- main ブランチに push すると GitHub Actions が自動でデプロイします(十数秒)
- ただしブラウザのキャッシュで**最大10分ほど古い表示のまま**のことがあります。
  変わっていないように見えたら Ctrl+F5(強制再読込)か、少し待ってから確認してください

## 掲載内容は data.js で編集

日々のアプリ紹介やお知らせは `data.js` で編集できます。サイト名を変更するときは、`siteName` に加え `index.html` のタイトル・検索向け情報・ロゴ・フッターも合わせて更新してください。

| 変えたいこと | data.js のどこ |
|---|---|
| お知らせの追加 | `news:` に1行足す |
| 公開ツールの表示/非表示 | `tools:` の各項目の `show: true/false` |
| ツールの名前・説明・リンク | `tools:` の `name` / `description` / `url` |
| 一覧で見せる短い説明 | `tools:` の `summary`（詳しい説明は `description`） |
| 用途の絞り込み | `audiences`: `education` / `research` / `measurement` の配列 |
| 対応環境の表示 | `platform` |
| 操作画面とその説明 | `screenshot` / `screenshotLabel` |
| トップで紹介するアプリ | `featuredRepo` / 各アプリの `featuredCopy` |
| 関心テーマの内容 | `interests:` の `items` |
| 問い合わせフォームのURL | `contact.googleFormUrl` |

## 新しいツールを載せたいとき

新規掲載は、公開済みで利用できるものを候補にし、所有者が選んだものだけを追加します。プライベートな開発を公開しません。既に掲載している試作アプリは、一覧の下の「公開中の試作アプリも見る」に分けています。

公開サイトの URL に `?admin=1` を付けて開くと、GitHub の公開リポジトリと
data.js を照合した管理パネルが出ます(訪問者には見えません)。
「＋ 未登録」のブロックをコピーして `tools: [` の中に貼るだけです。

## アプリの画像

- 実際のアプリを操作して撮った画像を `assets/` に置きます。生成した架空の操作画面は使いません。
- 成果や使い方が伝わる場面を選び、サンプル資料を使った場合は `screenshotLabel` に明記します。
- 氏名・メール・個人のファイルパス・カメラ映像・秘密情報が写っていないか確認してください。
- トップと一覧は画像の上部を優先して表示します。画像を押すと拡大でき、別タブで元画像も開けます。
- 今回のデザイン・検証記録は [design-qa.md](design-qa.md) を参照してください。

## Googleログイン掲示板・利用回数

Firebaseの公開設定と連携処理は実装済みです。接続・ルールを管理するときは [FIREBASE_SETUP.md](FIREBASE_SETUP.md) を参照してください。

- コメント閲覧: ログイン不要
- コメント投稿: Googleアカウントでログイン
- 利用回数: 各アプリの利用・ダウンロードリンクを開いた回数
- Firebase未接続時: 架空の数値や投稿は表示せず「準備中」と表示

## 自動取得している部分

氏名・所属・研究キーワード・論文・学会発表・経歴は researchmap
(https://researchmap.jp/7000029092)から自動取得しています。
researchmap を更新すればサイトも自動で最新になります(訪問者側に最大6時間のキャッシュ)。

## 検索エンジンについて

現在の `index.html` は `index,follow,max-image-preview:large` を設定しています。
今回のリニューアルで検索エンジン向けの公開設定や公開URLは変更していません。
