# 2026-09-20 View Pulse・アトラス・SeeReactの掲載整理

## 依頼と範囲

- View Pulseと経営学・マーケティング概念・尺度アトラスを「公開中の試作アプリ」から通常の公開ツール欄へ移動。
- View Pulseは記録結果の視線ヒートマップ画面、SeeReactは表情アバターの反応再生画面をカード画像に採用。
- 未完成・非公開のツールは追加しない。地域歴史防災は引き続き試作欄に置く。

## 画像の出典と安全性

- View Pulseはローカルで公開アプリの結果画面を描画し、架空のサンプル刺激画像と架空の視線サンプルだけを使って撮影した。カメラ映像・個人データは使っていない。
- SeeReactは `view-pulse-ios` のApp Store掲載用スクリーンショットから、表情アバターの反応再生画面を採用した。購入導線を表示しない実画面であることを確認した。
- 概念・尺度アトラスは公開アプリで概念と尺度を比較する実画面を継続使用する。

## 検証

- View Pulseの結果画面で `resultsScreen`、表示画像、ヒートマップCanvasの描画を確認。
- 変更後のデータで通常欄・試作欄の分類、画像パス、SeeReactのアバター画像を確認。
- JavaScript構文、差分の空白エラー、ローカルサイトの主要導線、390px幅の横はみ出しを確認する。

開始時から未追跡だった `AGENTS.md` と既存の `docs/` は今回の公開履歴に含めない。
