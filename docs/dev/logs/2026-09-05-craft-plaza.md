# 2026-09-05 M-Lab クラフト広場への更新

## 依頼と範囲

- サイト名を M-Lab クラフト広場に変更し、実際のアプリ画面が主役になる構成へ更新。
- 新規アプリの追加やリポジトリの公開範囲変更はしない。既存の公開アプリ6件・試作3件を維持。
- researchmap、Firebase認証・投稿・集計、各アプリの公開先、Pagesの公開経路は維持。

## 変更

- アイボリー・深緑・朱色のシンプルな作品一覧。トップに卒論セルフチェックの結果画面。
- 4つの用途フィルター、全角にも対応する複数語検索、0件時のリセット。
- 実画面の拡大、Escape／背景／閉じるボタン、フォーカス復帰、元画像へのリンク。
- 導入・README・感想の導線を整理。データの扱いと過去のお知らせは展開して読める。
- 掲示板はアプリ選択欄に整理。カードの「感想・質問」と選択欄を同期。

## 画像の出典と安全性

- PDF整理、提出物連続確認、Classroomレビューア: 対象アプリの実際のHTML・JSをローカルで描画。撮影専用の架空の候補・提出物を読み込み、既存のPDFや学生データは使っていない。
- Classroomレビューアの資料は撮影用に作成した架空の1ページPDF。提出物連続確認ではこの資料を画像として開いた実画面。
- 概念・尺度アトラス: 公開アプリで2概念の候補を表示した画面。
- リアクションメーター: 公開アプリのカメラ開始前の画面。カメラは開始していない。
- グループ抽選・卒論セルフチェック・View Pulse・地域歴史防災は既存の公開済み実画面を継続使用。
- デザイン検討の生成画像はレイアウトの参考に限り、アプリ画面として掲載していない。

## 検証

- JavaScript構文、差分の空白エラー、画像パスを検証。
- 自動ブラウザ検証: 4フィルター、全角・複数語・0件検索、クリア、9画像の拡大とリンク、Escapeとフォーカス復帰、話題の同期、過去のお知らせ、プロフィール展開。
- 1536 / 1024 / 768 / 390 / 320px で横はみ出しなし。1536pxと390pxのスクリーンショットを設計案と比較。
- Firebase未接続状態をテスト時だけ再現し、準備中表示・ログイン無効・アプリ一覧の継続動作を確認。
- テスト内だけの仮ログイン・長い表示名・本文で折り返し、文字数、HTMLが実行されないことを確認。実際のログイン・投稿・削除・ダウンロードは実行していない。
- 実ブラウザでも検索と画像の拡大を操作して確認。
- 検証の詳細・デザイン比較はルートの `design-qa.md`。公開反映の結果は完了報告を参照。
